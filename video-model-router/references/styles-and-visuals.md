# 风格、视觉与质感

本文件描述“画面看起来是什么样”，与 provider API 无关。风格必须落到可见元素，不能只写抽象形容词。

## 1. 风格栈

建议按七层组合，避免堆砌互相冲突的形容词：

```text
媒介：实拍 / 动画 / 3D / 定格 / 混合
时代：当代 / 复古 / 未来 / 架空
色彩：暖 / 冷 / 低饱和 / 高饱和 / 单色
光线：自然 / 硬光 / 柔光 / 霓虹 / 低调
镜头：广角 / 长焦 / 微距 / 变形宽银幕
质感：胶片颗粒 / 数字干净 / 绘画 / 黏土
情绪：克制 / 紧张 / 温暖 / 荒诞 / 史诗
```

示例：

```text
当代实拍，低饱和冷灰色调，阴天窗光，35mm 镜头，
轻胶片颗粒，克制、安静的家庭氛围。
```

## 2. 画面质感

| 质感 | 关键词 | 注意 |
|---|---|---|
| 电影感 | cinematic, filmic, 35mm, anamorphic | 需要具体镜头、光线、颗粒 |
| 纪录片 | documentary, handheld, naturalistic | 不要过度稳定 |
| 商业广告 | commercial, clean, product hero | 材质和光比要干净 |
| 复古胶片 | vintage, 8mm, VHS, halation | 不要同时要求超高锐度 |
| 数字高清 | clean digital, sharp, HDR | 不要同时要求强颗粒 |
| 动画 | cel-shaded, anime, 3D CG | 明确 2D 或 3D |
| 手绘 | hand-drawn, watercolor, ink wash | 说明线条和上色方式 |
| 黏土/定格 | claymation, stop-motion | 说明材质和运动节奏 |
| 超现实 | surreal, dreamlike, impossible geometry | 需要现实锚点 |

| 黑色电影 | 高反差、百叶窗阴影、烟雾 | 犯罪、悬疑、复古 |
| MV | 高饱和、快切、霓虹、抽帧 | 音乐、时尚、年轻化 |
| 复古胶片 | 颗粒、光晕、色偏 | 回忆、年代、文艺 |
| 极简广告 | 负空间、中心构图、柔光 | 产品、品牌、高端 |

| 3D 国漫 | 高精度建模、体积光、国风材质 | 仙侠、奇幻、动画 |

## 4. 导演风格参考

这些是“可借用的视听方法”，不是要求复制某位导演的作品。写提示词时优先写具体方法，再决定是否提名字。

| 参考 | 可借用方法 | 适合 | 风险 |
|---|---|---|---|
| 韦斯·安德森 | 严格对称、糖果色、平移、章回感 | 广告、萌系、复古趣味 | 容易变成纯模仿 |
| 王家卫 | 手持、抽帧、高饱和、霓虹、暧昧遮挡 | 都市、爱情、情绪 | 容易过度风格化 |
| 新海诚 | 天空、云层、丁达尔光、高饱和自然色 | 青春、治愈、风景 | 容易变成壁纸 |
| 宫崎骏 | 手绘、自然、飞行、柔和光 | 奇幻、童话、自然 | 需要明确是 2D 手绘 |
| 诺兰 | IMAX、实感、时间结构、低频音效 | 科幻、悬疑、史诗 | 不要把“诺兰”当万能词 |
| 扎克·施奈德 | 升格、高对比硬光、雕塑感构图 | 战斗、英雄、暗黑 | 慢动作容易过量 |
| 黑色电影 | 高反差、百叶窗、烟雾、倾斜构图 | 犯罪、侦探、悬疑 | 黑白与彩色要明确 |
| 今敏 | 现实/梦境无缝切换、匹配剪辑 | 梦境、心理、惊悚 | 需要清楚转场逻辑 |
| 庵野秀明 | 极端特写、静帧、倾斜、警告色 | 机甲、末日、焦虑 | 信息密度容易过载 |
| 鬼灭之刃 | 浮世绘纹样、水墨粒子、华丽战斗 | 日式战斗、特效 | 容易只写特效不写动作 |

## 5. 动漫与作画术语

| 术语 | 含义 | 写法示例 |
|---|---|---|
| 速度线 | 放射状线条表现高速 | 角色冲刺，背景速度线拉伸 |
| 残影 | 快速运动留下半透明残像 | 刀光留下残影轨迹 |
| 冲击波 | 攻击释放环形扩散 | 拳头命中，冲击波扩散，地面碎裂 |
| 粒子消散 | 物体碎裂为发光粒子 | 魔兽被斩成灰烬粒子消散 |
| 气流线 | 表现风或能量流动 | 能量释放，周身气流线旋转上升 |
| 夸张变形 | 喜剧式脸部或身体变形 | 角色震惊，脸部夸张变形 |
| 板野马戏团 | 大量飞行物螺旋追踪 | 数十道光束螺旋交错追踪 |
| 金田光 | 高光色块闪烁的爆炸特效 | 爆炸瞬间，彩色高光色块交替闪烁 |
| 三连定格 | 同一画面微调角度重复 | 震惊表情三连定格，逐帧微调角度 |

## 6. 主题到风格的映射

| 主题 | 首选风格 | 次选 | 避免 |
|---|---|---|---|
| 仙侠/修真 | 3D 国漫、国风概念设计 | 水墨、工笔 | 纯赛博朋克 |
| 古风/历史 | 水墨、工笔、古典绘画 | 低饱和实拍 | 高饱和霓虹 |
| 赛博朋克/科幻 | 写实 CG、概念设计 | 霓虹实拍 | 手绘儿童风 |
| 现实/人物 | 电影摄影写实 | 纪录片 | 3D 卡通 |
| 美食 | 美食广告摄影 | 微距实拍 | 低质量 CG |
| 自然风光 | 风光摄影、航拍 | 延时 | 过度滤镜 |
| 动漫 | 日漫赛璐璐、国漫 3D | 厚涂 | 写实真人 |
| 产品 | 商业广告、极简 | 3D 渲染 | 杂乱背景 |
| 恐怖 | 低调光、冷色、长镜头 | 手持伪纪录 | 高饱和喜剧色 |
| 喜剧 | 高调光、快切、夸张表演 | 复古广告 | 沉郁低饱和 |

## 7. 风格一致性规则

1. 只保留一个主导风格，最多一个辅助风格。
2. 不要同时写互相冲突的质感，例如“8mm 胶片”与“4K 超清”、“强颗粒”与“绝对锐利”。
3. 参考图是风格的主锚点。参考图与文字冲突时，先统一参考图。
4. 人物参考、场景参考、风格参考要分开说明继承什么、不继承什么。
5. 风格词必须落到可见元素：光源、镜头、色调、材质、颗粒、构图。
6. 不要堆叠超过两位导演或超过三种艺术运动。
7. 产品广告优先控制材质、比例、光比，不要用大量叙事风格词。
8. 写实人物避免“完美皮肤、塑料感、过度锐化”，加入自然皮肤纹理和真实光线。

## 8. 风格提示词模板

```text
媒介与时代：[实拍/动画/3D；当代/复古/未来]。
色彩与光线：[主色 + 辅色；光源类型 + 方向 + 时间]。
镜头与质感：[焦段/景深/画幅；颗粒/锐度/材质]。
情绪与氛围：[克制/紧张/温暖/荒诞]。
参考锚点：[具体片名、摄影风格或艺术运动，最多 1-2 个]。
避免：[风格漂移、塑料感、过度锐化、错误媒介]。
```

## 9. 风格审阅清单

- [ ] 主导风格只有一个。
- [ ] 没有互相矛盾的质感词。
- [ ] 光源、色调、材质都能被摄影机拍到。
- [ ] 参考图与文字的风格一致。
- [ ] 人物、场景、道具的继承边界明确。
- [ ] 没有把“电影感”当作唯一风格描述。
- [ ] 没有要求画面文字、Logo、水印。
