# 镜头语言与视听语法

本文件是跨模型的镜头语言参考。只描述“画面怎么拍”，不绑定任何视频模型 API。

## 1. 镜头大小（景别）

| 景别 | 画面范围 | 主要用途 | 风险 |
|---|---|---|---|
| 大远景 | 人物极小，环境/地貌为主 | 建立世界、孤独感、规模 | 人物动作看不清 |
| 远景 | 人物全身且环境完整 | 交代空间、人物与环境关系 | 面部情绪弱 |
| 全景 | 人物全身可见 | 动作、走位、空间调度 | 背景容易抢主体 |
| 中远景 | 膝盖以上 | 动作与关系兼顾 | 信息不够聚焦 |
| 中景 | 腰部以上 | 对话、动作、关系 | 容易变成普通正反打 |
| 中近景 | 胸部以上 | 表演、情绪、手势 | 空间关系变弱 |
| 近景 | 肩部以上 | 表情、反应、台词 | 缺少环境信息 |
| 特写 | 面部或物件局部 | 关键信息、情绪、证据 | 连续使用会失去重量 |
| 大特写 | 眼睛、嘴唇、文字、材质 | 极端强调 | 容易显得广告化 |

### 景别连接

- 相邻景别过渡最自然：全景 → 中景 → 近景 → 特写。
- 跨级跳切有冲击力，适合转场、惊吓、信息揭露；不要连续滥用。
- 同一景别连续超过 4 镜容易单调，需要用内容、角度或运动制造变化。
- 场景内优先形成“远 → 中 → 近”的推近结构；场景结束时可以“近 → 远”拉回空间。

## 2. 摄影角度

| 角度 | 视觉效果 | 适合场景 |
|---|---|---|
| 平视 | 客观、平等、自然 | 日常写实、对话 |
| 微俯拍 | 轻微压迫、观察感 | 桌面、手部、证据 |
| 俯拍 | 人物变小、被环境压住 | 无力、制度、空间关系 |
| 极高俯拍 / 鸟瞰 | 全知、几何、规模 | 建立镜头、结尾升华 |
| 仰拍 | 人物变大、英雄感、威胁感 | 英雄、权力、压迫 |
| 低机位 | 贴近地面、动物/脚步视角 | 追逐、宠物、紧张感 |
| 荷兰角（倾斜） | 失衡、不安、精神错乱 | 惊悚、心理崩裂 |
| 主观视角 / POV | 观众代入角色 | 沉浸、惊悚、发现 |
| 过肩 | 关系与距离 | 对话、对峙、窥视 |
| 鱼眼 | 畸变、夸张、荒诞 | MV、喜剧、超现实 |

## 3. 运镜

| 运镜 | 画面变化 | 适合表达 | 执行要点 |
|---|---|---|---|
| 固定机位 | 画面框架不动 | 观察、克制、稳定 | 必须有动作或光影变化 |
| 推镜头 | 逐渐靠近主体 | 聚焦、压迫、发现 | 写清起点、终点、速度 |
| 拉镜头 | 逐渐远离主体 | 揭示、疏离、收束 | 结尾要给出新信息 |
| 摇镜头 | 机位不动，镜头旋转 | 扫视、发现、空间连接 | 写清方向和停止点 |
| 移镜头 | 机位平移 | 跟随环境、展示空间 | 保持主体在画面中的位置 |
| 跟拍 | 跟随主体移动 | 行走、追逐、沉浸 | 写清跟随距离和方向 |
| 环绕 | 围绕主体旋转 | 英雄感、产品展示、关系变化 | 写明角度与结束位置 |
| 升降 | 机位上下移动 | 揭示高度、权力变化 | 写清起点高度与终点高度 |
| 手持跟拍 | 有呼吸感的晃动 | 纪实、紧张、临场 | 不要写成无目的剧烈晃动 |
| 斯坦尼康 | 平滑长距离跟随 | 长镜头、走位、空间穿越 | 提前设计路径与遮挡 |
| 变焦 | 焦距变化，机位不变 | 强调、压缩空间 | 不要和推镜头混写 |
| 希区柯克变焦 | 推拉与变焦反向 | 眩晕、震惊、失衡 | 只用于关键情绪点 |
| 焦点转换 | 焦点从一个主体转到另一个 | 引导注意力、关系变化 | 写清前后焦点对象 |
| 航拍 / 无人机 | 高空移动视角 | 地理、规模、开场/收尾 | 写清高度、方向、终点 |

### 运镜硬规则

1. 一个镜头只指定一个主要运镜。不要同时写推、拉、摇、环绕。
2. 非固定运镜必须写清：起点、方向、速度、跟随对象、停止位置。
3. 运镜必须和景别变化兼容。例如“特写环绕”容易让主体出画。
4. 一镜到底要在开头就声明“单一连续镜头、全程无剪切”。
5. 镜头运动不能替代动作设计。主体必须在画面里发生可见变化。

## 4. 构图

| 构图 | 效果 | 适用 |
|---|---|---|
| 三分法 | 自然、稳定、易读 | 大多数场景 |
| 中心构图 | 仪式感、压迫、广告 | 产品、英雄、对称空间 |
| 对称构图 | 秩序、控制、荒诞 | 韦斯·安德森式、制度空间 |
| 框式构图 | 被困、窥视、层次 | 门框、窗户、走廊 |
| 引导线 | 视线被带向主体 | 道路、走廊、轨道 |
| 负空间 | 孤独、留白、呼吸 | 情绪片、极简广告 |
| 前景遮挡 | 偷窥、纵深、转场 | 对话、悬疑、遮挡转场 |
| 纵深构图 | 空间层次、人物关系 | 室内、街景、追逐 |
| 低地平线 | 人物高大、天空开阔 | 英雄、史诗 |
| 高地平线 | 人物被环境压住 | 无力、纪实、荒凉 |

## 5. 光线

| 光线 | 效果 | 适合 |
|---|---|---|
| 自然光 | 真实、克制 | 日常写实、纪录片 |
| 窗光 | 柔和、亲密 | 室内人物、家庭 |
| 黄金时刻 | 温暖、怀旧、浪漫 | 爱情、旅行、回忆 |
| 蓝调时刻 | 冷峻、孤独、科幻 | 夜戏、城市、悬疑 |
| 阴天散射光 | 均匀、低对比 | 写实、纪实 |
| 硬光 | 强阴影、戏剧性 | 黑色电影、动作 |
| 柔光 | 低反差、干净 | 商业、人物、美容 |
| 侧逆光 | 轮廓、空气感 | 电影感、史诗 |
| 伦勃朗光 | 面部三角光、古典 | 肖像、戏剧 |
| 实用光源 | 台灯、霓虹、屏幕 | 真实空间、夜戏 |
| 霓虹光 | 高饱和、赛博感 | 都市、科幻、MV |
| 体积光 | 光柱、尘埃、神圣感 | 森林、舞台、史诗 |
| 荧光灯 | 冷白、机构感 | 医院、办公室、洗衣店 |
| 月光 | 冷蓝、安静 | 夜外景、神秘 |
| 低调光 | 大面积暗部、悬疑 | 惊悚、黑色电影 |
| 高调光 | 明亮、干净、商业 | 广告、喜剧、时尚 |

## 6. 色彩与质感

| 方向 | 关键词 | 使用建议 |
|---|---|---|
| 青橙 | teal and orange | 商业大片，慎用于写实日常 |
| 暖调 | warm grade, amber | 家庭、回忆、食物 |
| 冷调 | cool grade, blue-gray | 悬疑、孤独、机构 |
| 低饱和 | desaturated, muted | 写实、严肃、文艺 |
| 高饱和 | saturated, vivid | MV、动漫、广告 |
| 黑白 | monochrome, high contrast | 黑色电影、实验 |
| 漂白 | bleach bypass | 战争、粗粝、纪实 |
| 胶片 | film grain, halation | 复古、电影感 |
| 数字干净 | clean digital, sharp | 商业、产品、科技 |

## 7. 焦点与镜头特性

| 特性 | 效果 | 风险 |
|---|---|---|
| 浅景深 | 主体突出、背景虚化 | 空间信息减少 |
| 深景深 | 环境与人物都清晰 | 主体可能不突出 |
| 长焦压缩 | 空间被压扁、人物靠近 | 运动方向不明显 |
| 广角畸变 | 空间夸张、临场 | 人脸易变形 |
| 微距 | 材质、细节、纹理 | 运动范围小 |
| 移轴 | 微缩模型感 | 不适合写实叙事 |
| 变形宽银幕 | 横向光晕、电影感 | 与竖屏冲突 |
| 镜头光晕 | 光源溢出 | 容易廉价 |
| 运动模糊 | 速度感 | 过度会糊 |
| 抽帧 | 时间撕裂、风格化 | 不适合自然写实 |

## 8. 节奏与剪辑

| 手法 | 效果 | 适用 |
|---|---|---|
| 长镜头 | 沉浸、时间真实 | 情绪、走位、空间 |
| 快切 | 紧张、信息密集 | 动作、蒙太奇、MV |
| 硬切 | 直接、干脆 | 大多数场景转换 |
| 匹配剪辑 | 视觉或动作连续 | 转场、时间跳跃 |
| 跳切 | 时间断裂、焦虑 | 心理、实验、短视频 |
| 交叉剪辑 | 平行叙事、悬念 | 追逐、对峙、多线 |
| 蒙太奇 | 压缩时间、并列信息 | 建立、训练、过程 |
| 慢动作 | 强调瞬间、仪式感 | 动作、情绪、产品 |
| 延时 | 时间流逝 | 城市、自然、建设 |
| 定格 | 强调、结束、漫画感 | 结尾、风格化 |

## 9. 声音设计

| 声音 | 作用 | 示例 |
|---|---|---|
| 环境音 | 建立空间真实感 | 雨声、机器声、街道声 |
| 动作音效 | 强调物理接触 | 脚步、关门、杯子碰撞 |
| Foley | 细节质感 | 衣料摩擦、纸张、钥匙 |
| 对白 | 信息与关系 | 角色台词，标情绪和语气 |
| 旁白 | 叙述、内心、说明 | 第一人称或纪录片 |
| 配乐 | 情绪与节奏 | 主题、推进、收束 |
| 音桥 | 连接两个场景 | 上一场声音延续到下一场 |
| 声音先行 | 先听见再看见 | 悬念、转场、发现 |
| 静默 | 制造压力 | 关键停顿、震惊 |

## 10. 场景到镜头的选择

| 场景 | 优先景别 | 优先运镜 | 光线 | 注意 |
|---|---|---|---|---|
| 产品展示 | 特写、中近景 | 环绕、缓推 | 柔光/硬光按质感 | 材质和比例一致 |
| 人物对话 | 中景、中近景 | 固定、轻微推近 | 窗光/实用光 | 不要全程正反打 |
| 追逐 | 全景、中景 | 跟拍、手持 | 自然光/霓虹 | 方向与空间连续 |
| 悬疑 | 中景、特写 | 固定、慢推 | 低调光 | 不要提前揭示信息 |
| 情绪 | 中近景、近景 | 固定、极慢推 | 柔光/窗光 | 留白比特写更重要 |
| 风景 | 大远景、远景 | 航拍、缓慢横移 | 黄金/蓝调 | 需要尺度参照 |
| 食物 | 特写、大特写 | 微距、缓推 | 侧逆光/柔光 | 材质、蒸汽、油光 |
| 动漫战斗 | 中景、特写 | 环绕、快切 | 高对比 | 特效与动作分层 |
| 音乐卡点 | 全景到特写 | 快切、匹配剪辑 | 霓虹/舞台 | 切点跟节奏 |
| 一镜到底 | 全景到中近景 | 跟拍、升降、环绕组合 | 统一光源 | 写清路径和终点 |

## 11. 一镜到底设计清单

- [ ] 开头声明“单一连续镜头、全程无剪切、无转场、无蒙太奇”。
- [ ] 只设计一条连续摄影机路径。
- [ ] 路径有明确起点、方向、经过点、终点。
- [ ] 主体始终在画面内，且占画比例足够。
- [ ] 不设计无法由一次运镜完成的转身、穿越、换景。
- [ ] 场景切换只通过空间移动、遮挡、门窗、黑暗或运动模糊完成。
- [ ] 结尾有明确停止状态，便于下一段或剪辑。
- [ ] 不用“镜头1/镜头2”这类会诱发多镜头的写法。


## 13. 常见错误

1. 一个镜头写多种运镜。
2. 只写“电影感”，不写具体光源、镜头、色调。
3. 只写情绪词，不写可见动作。
4. 一镜到底却写“切至”“镜头2”。
5. 镜头时长装不下动作和对白。
6. 主体位置、视线、运动方向前后不一致。
7. 用转场掩盖空间跳变。
8. 连续使用同一景别和同一角度。
9. 画面文字、字幕、Logo 未明确排除。
10. 把参考图的背景、构图、光线一起继承，导致风格漂移。
