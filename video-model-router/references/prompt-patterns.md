# 跨模型提示词模式

本文件定义与 provider 无关的提示词结构。provider 只负责把这些语义映射到自己的字段和语法。

## 1. 基本结构

```text
[时长 + 画幅 + 模式]
[主体与场景]
[连续动作或时间轴]
[镜头路径 / 景别 / 角度]
[光线 / 色调 / 质感]
[声音 / 对白 / 音乐]
[继承与不继承声明]
[负面约束]
```

不是每次都要写满八段，但重要信息必须前置。

## 2. 时长与画幅

- 时长必须明确，且落在 provider 的能力范围内。
- 画幅必须明确：16:9、9:16、1:1、4:3、3:4、21:9。
- 不要把 provider 的字段值写进创作提示词，例如不要写 `seconds: "8"`；写“8 秒”。
- 一镜到底必须明确“单一连续镜头，全程无剪切”。

## 3. 主体定义

- 主体用 2–3 个稳定、可见的特征锁定：身份、服装、体型、材质、颜色。
- 有人物参考图时，明确继承什么：脸、发型、服装、体型、配饰。
- 明确不继承什么：背景、姿势、构图、裁切、文字、光线。
- 多主体时给每个主体稳定标签，避免“同一个人”在不同镜头漂移。

## 4. 动作描述

- 动作必须具体到身体部位、速度、力度、方向、终点。
- 写动作的因果和惯性：借转身惯性抬手、从停顿过渡到起步。
- 一个镜头只保留一个主要动作目标；不要在一秒内塞入多个高潮。
- 情绪用可见动作表达，不写“他很悲伤”，写“他停住，手指压住卡片边缘，视线落在地面”。

## 5. 一镜到底模板

```text
单一连续镜头，一镜到底，全程无剪切、无转场、无蒙太奇。
时长 [N] 秒，[画幅]。

[场景与主体]。主体从 [首状态] 开始，沿 [路径] 完成 [一个连续动作]，
最后停在 [尾状态]。

镜头从 [起点机位/景别] 开始，以 [唯一运镜] 沿 [方向] 移动，
经过 [中间参照物]，最后停在 [终点机位/景别]。
全程保持单一摄影机路径，不切换景别，不出现第二个动作高潮。

[光线/色调/质感]。
[声音/对白]。
继承：[参考素材中要保留的特征]。
不继承：[参考素材中不能带入的背景、构图、光线等]。
不出现字幕、文字、水印、Logo；不出现主体分身、变形、闪烁或突然消失。
```

## 6. 首帧图生视频模板

```text
以 [首帧参考] 为首帧。保持 [人物/产品/场景] 的 [身份、外观、服装、比例] 一致。
不继承参考图的 [背景/构图/姿势/光线]。

从首帧状态开始，[主体] 完成 [一个连续动作]。
镜头 [固定/缓慢推近/跟随]，最后停在 [尾状态]。

[光线/色调/声音]。
不出现字幕、文字、水印、Logo。
```

## 7. 首尾帧模板

```text
以 [首帧] 为起点，以 [尾帧] 为终点。
中间过程必须连续、自然，不能跳切。
[主体] 从 [首状态] 通过 [动作路径] 到达 [尾状态]。
镜头 [运动方式]，保持 [构图/轴线/光线] 连续。
不出现第二个人物、分身、变形、突然消失。
```

## 8. 参考图模板

```text
以 <Picture 1> 的 [角色/产品] 为参考，保持 [身份/材质/服装/比例] 一致。
不继承参考图中的 [背景/构图/光线/文字]。

[主体] 在 [场景] 中完成 [动作]。
镜头 [景别 + 角度 + 运镜]。
[光线/色调/风格]。
不出现字幕、文字、水印、Logo。
```

## 9. 参考音频模板

```text
以 <Audio 1> 的 [节奏/音色/环境氛围] 为参考。
画面 [主体动作] 与音频节拍对齐。
[对白/旁白/环境声/音乐] 设计：[具体声音]。
不出现字幕、文字、水印、Logo。
```

## 10. 对白模板

```text
[角色A]（情绪，语气）："[台词]"
[角色B]（情绪，语气）："[台词]"

说话时画面：[可见动作 + 镜头景别]。
听者反应：[可见表情或动作]。
音频：[环境声 + 配乐 + 停顿]。
```

对白硬规则：

- 台词必须口语化。
- 每句台词标注角色和情绪。
- 台词长度必须能放进镜头时长。
- 镜内多人对话要控制说话人数，超出 provider 限制就拆镜。
- 不要让画面文字承担台词；台词走声音。

## 11. 时间轴模板

仅在需要精确节奏时使用：

```text
0–[N] 秒：[镜头运动] + [主体动作] + [空间变化]
[N]–[M] 秒：[镜头运动] + [主体动作] + [空间变化]
[M]–[总时长] 秒：[镜头运动] + [主体动作] + [收束状态]
```

规则：

- 时间段必须连续、无重叠、覆盖完整时长。
- 每段同时写镜头和主体。
- 不要把多个场景硬塞进一个短段。
- 模型不支持时间戳时，用自然语言顺序描述，不要伪造时间码。

## 12. 负面约束模板

```text
不出现字幕、文字、水印、Logo。
不出现主体分身、双胞胎、重复人物。
不出现面部变形、肢体畸形、手指错误、穿模。
不出现突然消失、瞬移、无过渡的场景跳变。
避免风格漂移、塑料皮肤、过度锐化、过度平滑。
```

负面约束要具体到错误品类，不要只写“不要低质量”。

## 13. 继承与不继承

每个参考素材都必须写两件事：

```text
继承：[角色身份、服装、材质、风格、运镜节奏]
不继承：[背景、构图、光线、文字、故事背景、声音]
```

这是跨镜头一致性的第一道保险。

## 14. 提示词审阅清单

- [ ] 时长、画幅、模式明确。
- [ ] 主体有稳定可见特征。
- [ ] 动作具体到身体部位与终点。
- [ ] 只有一个主要运镜。
- [ ] 光线、色调、质感可拍。
- [ ] 声音与对白有明确归属。
- [ ] 参考素材的继承边界明确。
- [ ] 没有互相冲突的要求。
- [ ] 时长能装下动作与台词。
- [ ] 一镜到底没有“镜头2/切至”。
- [ ] 已排除字幕、文字、水印、Logo。
- [ ] provider 限制已通过 capabilities 或 dry-run 校验。
