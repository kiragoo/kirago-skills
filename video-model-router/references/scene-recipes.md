# 场景配方

本文件按内容类型给出跨模型可复用的镜头配方与避坑点。它不绑定任何 provider 字段。

## 1. 产品广告

**目标**：材质、比例、卖点清晰。

```text
主体：产品 + 2–3 个稳定特征。
镜头：中心构图，黑/白背景，柔光或硬光。
运动：缓慢旋转、缓推、焦点转换。
细节：材质纹理、边缘高光、倒影、蒸汽/水珠。
负面：变形、比例错误、多余文字、水印。
```

避坑：

- 不要在 5 秒内塞入多个卖点。
- 不要让背景抢产品边缘。
- 产品参考图只用一张清晰主视图，避免多视图识别错。

## 2. 双人对白

**目标**：关系、权力、情绪变化。

```text
镜头：双人中景 → 过肩 → 听者反应。
光线：窗光或实用光，保持轴线。
动作：一句台词配一个反应动作。
声音：对白 + 环境声 + 停顿。
```

避坑：

- 不要全程正反打。
- 台词长度要匹配镜头时长。
- 说话人与听者的视线方向必须一致。

## 3. 动作/追逐

**目标**：方向清楚、动作有因果。

```text
镜头：全景建立空间 → 中景跟拍 → 特写冲击。
运动：跟拍、手持、快速摇镜，一次只用一个。
动作：起步 → 阻碍 → 反应 → 继续。
负面：漂浮、滑步、肢体变形。
```

避坑：

- 空间方向不能反转。
- 不要在一个短镜头里塞入完整打斗。
- 复杂物理和多人互动要降低预期。

## 4. 恐怖/悬疑

**目标**：延迟揭示、制造不安。

```text
镜头：固定中景、慢推、背影、框中框。
光线：低调光、实用光源、冷色。
声音：环境声、低频、突然的静默。
信息：先给反应，再给原因。
```

避坑：

- 不要提前展示怪物全貌。
- 不要用高饱和喜剧色。
- 跳吓只能用一次，连续使用会失效。

## 5. 情绪/文艺

**目标**：克制、留白、环境声。

```text
镜头：固定中景、中近景、少量慢推。
构图：负空间、框中框、人物偏离中心。
光线：窗光、阴天、低饱和。
声音：环境声为主，配乐极少。
```

避坑：

- 不要把“克制”写成全程静止。
- 情绪必须落到动作：停顿、手指、呼吸、视线。
- 长镜头内部必须有变化。

## 6. 仙侠/古风

**目标**：国风空间、动作与特效分层。

```text
风格：3D 国漫、水墨、工笔。
镜头：远景建立山水 → 中景对峙 → 特写剑/眼。
动作：拔剑、转身、衣摆、气流。
特效：能量波、粒子、法阵、残影。
声音：鼓点、剑鸣、风声。
```

避坑：

- 不要只写特效不写动作。
- 古风空间要有建筑、山石、云雾等锚点。
- 特效不能遮挡人物身份。

## 7. 音乐卡点

**目标**：画面切点与节奏同步。

```text
素材：多张图或多段视频。
节奏：明确 BPM 或“跟随鼓点”。
切点：动作转折、重拍、颜色变化。
运动：推拉、环绕、快切，但每镜只用一个。
```

避坑：

- 不要均匀切，要卡在动作和重拍上。
- 素材数量不要超过 provider 限制。
- 音频和画面必须同时描述。

## 8. 一镜到底情绪戏

**目标**：空间连续、情绪递进。

```text
镜头：单一连续路径，跟拍或环绕。
主体：一个连续动作，从 A 状态到 B 状态。
空间：起点、经过点、终点明确。
声音：环境声连续，可有音桥。
```

避坑：

- 不要写切镜。
- 不要让主体出画太久。
- 复杂转身和换景要拆成可执行的路径。
- 结尾必须有明确停止状态。

## 9. 科普/教育

**目标**：信息清楚、视觉化准确。

```text
风格：半透明 CGI、医学可视化、干净背景。
镜头：缓推、剖面、跟随流体。
信息：一次只讲一个机制。
声音：克制旁白 + 轻环境音。
```

避坑：

- 不要把说明文字画进画面。
- 不要用夸张特效掩盖信息。
- 机制要有空间锚点：血管、器官、粒子。

## 10. 萌宠/短视频

**目标**：可爱、动作清楚、记忆点。

```text
镜头：低机位、中近景、跟随。
动作：一个意外或反差。
光线：自然光、暖色。
声音：环境声 + 轻微拟音。
```

避坑：

- 不要写过多人类动作。
- 不要让宠物变形或出现第二只同款。
- 短时长只需一个记忆点。

## 11. 场景配方通用检查

- [ ] 主体的稳定特征足够。
- [ ] 场景有明确空间锚点。
- [ ] 动作可以在时长内完成。
- [ ] 镜头只用一个主要运镜。
- [ ] 光线方向明确。
- [ ] 声音有具体来源。
- [ ] 负面约束具体。
- [ ] 参考素材继承边界明确。
- [ ] provider 限制已校验。
