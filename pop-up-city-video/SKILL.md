# 纸上城市动画

从城市简报、图像素材和镜头配置生成可复现的 Three.js/WebGL 动画。换城市只换项目的数据和素材，除非用户提出新效果，否则不重写引擎。

1. **确定简报。** 只有城市名时，默认 50 秒、9:16、24 fps、无音轨。按当地特色选择 3–4 个地标及一条视觉游览线；不把纸艺示意画成可导航地图。对同名城市或确需精确复原而证据不足的情况再澄清；地名和建筑特征需要时核验。江南的船不是默认配置，其他城市的交通方式、前景与地貌要按题材选择，可省略移动物件。
2. **生成素材。** 读 [素材与构图](references/art-direction.md)。用环境提供的内置生图工具分别生成一张完整俯视底图、桌面和纸纹、每处地标的透明底素材，前景和移动物件按需生成。保留原图，按返回结果核实路径及有效透明通道。用户要求精确模型版本时，只在服务确认时报告该版本；生成工具缺失就报告限制，不把外部图库或占位图当作已生成正式素材。
3. **编译项目。** 读 [配置与运行](references/project.md)，写 `city.json`，用 `scripts/build_project.py` 将其和图像素材编译到新目录。地图上的 `at: [x,z]` 应按实际生成的纹理定位；调整只改城市配置。脚本自动布置开场折叠、每站立起与停留、日落与点灯、结尾拉升。修改地标或镜头时先保留同一地图和既有编号。
4. **预览后导出。** 用 `node render.mjs preview` 查看折叠中段、每个地标半立/全立、结尾全景；检查贴图透明、基座不穿纸、建筑不被裁断、停留可读、灯具未过曝。长视频先用 `node render.mjs clip 0 4` 验证渲染，再用 `node render.mjs video` 逐帧导出；没有 WebGL/FFmpeg 时说明完成到了哪一步。用 ffprobe 和完整解码验收帧数、比例、时长。
5. **交付。** 给实际 MP4 和可重渲染项目，包括场景配置与已用素材；注明非实拍、示意底图和音轨情况。若发送渠道限制文件大小，保留高质量原片，并生成同等时长的轻量预览，不裁短冒充原片。
