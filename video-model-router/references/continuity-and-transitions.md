# 连续性与转场

本文件解决“镜头之间为什么跳、怎么不跳”。适用于单镜头一镜到底、多镜头序列和视频延长。

## 1. 连续性的六个维度

| 维度 | 要锁什么 | 常见断裂 |
|---|---|---|
| 身份 | 脸、发型、体型、年龄 | 换脸、双胞胎 |
| 服装 | 款式、颜色、材质、配饰 | 中途换衣、鞋子变化 |
| 道具 | 位置、归属、状态 | 道具消失、换手 |
| 空间 | 房间布局、门窗、家具 | 瞬移、方向反转 |
| 动作 | 姿势、速度、方向、惯性 | 坐着变站着、动作回放 |
| 光线 | 光源方向、色温、强度 | 白天变夜晚、阴影反转 |

## 2. 镜头状态表

多镜头或延长必须为每个镜头记录：

```text
镜头编号：
开始状态：位置 / 姿势 / 朝向 / 手持物 / 光线
结束状态：位置 / 姿势 / 朝向 / 手持物 / 光线
摄影机：机位 / 景别 / 角度 / 运动方向
与下一镜连接：动作 / 视线 / 遮挡 / 声音 / 硬切
不可变要素：人物身份、服装、场景、核心道具
```

## 3. 首尾状态对齐

相邻镜头必须满足至少一种：

1. **动作连续**：上一镜结束动作 = 下一镜开始动作。
2. **视线连续**：上一镜看向的方向 = 下一镜出现的对象。
3. **空间连续**：下一镜从上一镜的同一空间开始。
4. **声音连续**：上一镜声音延续到下一镜。
5. **遮挡连续**：通过门、墙、人物、黑暗完成切换。
6. **匹配构图**：两个画面的形状、颜色、位置形成匹配。

如果不满足任何一条，必须在提示词中写明确切场或时间跳跃，不能假装连续。

## 4. 一镜到底约束

- 只允许一条连续摄影机路径。
- 不允许切镜、淡入淡出、叠化、闪白、蒙太奇。
- 场景转换只能靠摄影机移动、角色走动、遮挡、黑暗、门窗、运动模糊。
- 主体必须始终在画面内，或通过明确遮挡短暂离开再回到画面。
- 结尾必须有明确停止状态。
- 不要写“镜头1/镜头2/切至/下一镜”。

### 一镜到底路径模板

```text
起点：[机位 + 景别 + 主体位置]
路径：[前进/后退/横移/环绕/升降] + [经过点]
终点：[机位 + 景别 + 主体位置]
主体动作：[一个连续动作]
遮挡/转场：[如有，只允许由空间或物体完成]
```

## 5. 多镜头衔接

| 衔接方式 | 什么时候用 | 怎么写 |
|---|---|---|
| 动作接动作 | 同一角色连续动作 | 上一镜抬手，下一镜手已伸向门把 |
| 视线接对象 | 角色看到某物 | 上一镜看向窗外，下一镜窗外景色 |
| 声音先行 | 强化悬念或空间 | 下一场声音先进入上一场结尾 |
| 匹配剪辑 | 形状/动作/颜色相似 | 圆形车轮接圆形钟表 |
| 遮挡转场 | 门、墙、人物经过镜头 | 角色走出画面，下一镜从新空间进入 |
| 硬切 | 场景/时间明确变化 | 不假装连续，直接切换 |
| 时间跳跃 | 需要省略过程 | 明确“数小时后”“第二天” |

## 6. 视频延长

延长不是“再写一段完全独立的内容”。必须承接：

```text
承接上一段尾帧的 [位置/姿势/光线/动作方向]。
只描述新增时间区间。
第一秒必须与上一段最后一帧兼容。
最后给出新的停止状态。
不得突然换装、换景、换人物、换光线。
```

如果 provider 支持尾帧回传，优先使用尾帧作为下一段首帧。

## 7. 连续性负面约束

```text
不得出现无过渡的位置跳变。
不得出现人物服装、发型、配饰突然变化。
不得出现道具消失或换手。
不得出现场景布局、门窗位置、家具位置变化。
不得出现光线方向、色温、时间突然变化。
不得出现动作回放、倒放或重复同一动作。
不得出现人物分身、双胞胎。
```

## 8. 生成后审计

### 逐镜检查

- 首帧与上一镜尾帧是否兼容。
- 人物身份、服装、发型是否一致。
- 核心道具是否存在、位置是否合理。
- 场景布局与光线方向是否一致。
- 动作方向与速度是否连续。
- 是否出现切镜、闪白、跳帧。
- 是否出现字幕、文字、水印、Logo。

### 技术检查

```bash
ffprobe -v error -show_entries format=duration \
  -show_entries stream=width,height,r_frame_rate,codec_name \
  -of json output.mp4
```

- 时长是否符合预期。
- 分辨率、帧率是否符合预期。
- 是否只有一条视频流和一条音频流。
- 是否有黑帧、冻帧、音频断裂。

### 镜头边界检查

使用 PySceneDetect 检测切点：

```bash
scenedetect -i output.mp4 detect-content list-scenes
```

对一镜到底：理想结果是只有 1 个镜头。  
如果检测出多个镜头，不一定代表一定切了，但需要人工复核；如果确实切了，应重生成或调整提示词。

## 9. 常见断裂与修复

| 症状 | 根因 | 修复 |
|---|---|---|
| 飞机座椅变家里椅子 | 未声明场景切换 | 增加过渡动作或明确切场 |
| 人物坐着变站着 | 首尾状态未对齐 | 写清上一镜尾姿势与下一镜首姿势 |
| 服装变化 | 参考素材继承边界不清 | 明确继承服装，不继承背景 |
| 道具消失 | 未锁定道具位置 | 写清道具所在手/桌面/画面位置 |
| 光线跳变 | 未锁光源方向 | 写清光源、方向、色温 |
| 动作重复 | 提示词重复同一动作 | 区分动作指纹，避免复制上一段 |
| 人物分身 | 多视图/多主体指代不清 | 用单人独立参考图，明确主体标签 |
| 转场很硬 | 只做 concat 硬切 | 设计动作/视线/遮挡/声音连接 |
| 一镜到底却切镜 | 写了镜头1/镜头2 | 改成单一连续镜头，删除切镜词 |

## 10. 连续性审阅清单

- [ ] 每个镜头都有开始状态和结束状态。
- [ ] 相邻镜头至少有一种连接方式。
- [ ] 人物身份、服装、道具、场景有不可变清单。
- [ ] 光线方向与色温一致。
- [ ] 动作方向与惯性连续。
- [ ] 没有无过渡的场景跳变。
- [ ] 延长部分只写新增区间，并承接尾帧。
- [ ] 一镜到底没有切镜词。
- [ ] 生成后已用 ffprobe 和镜头检测复核。
